# Study MBBS Abroad Landing Page

This project is a responsive landing page for "Study MBBS Abroad" created as part of the Front-End Development Intern application for University Insights.

## Project Structure

-   \`index.html\`: The main HTML file containing the structure of the landing page.

## Setup Instructions

1. Clone this repository to your local machine.
2. Open the \`index.html\` file in a web browser to view the landing page.

## Features

-   Responsive design that works on desktop and mobile devices
-   Navigation menu with smooth scrolling
-   Sections for key information about studying MBBS abroad
-   Lead generation form with client-side validation
-   Integration with Google Analytics and Facebook Pixel (placeholders included)

## SEO Optimization

The landing page includes basic SEO optimizations:

-   Descriptive title tag
-   Meta description
-   Semantic HTML structure
-   Relevant headings (H1, H2)

## Performance Considerations

-   Minimal use of external resources
-   Efficient CSS using a mobile-first approach
-   JavaScript for enhanced functionality without relying on heavy libraries

## Tracking Integration

Placeholders for Google Analytics and Facebook Pixel are included in the HTML file. Replace the placeholder IDs with your actual tracking IDs to enable analytics:

-   Google Analytics: Replace \`GA_MEASUREMENT_ID\` with your Google Analytics measurement ID.
-   Facebook Pixel: Replace \`YOUR_PIXEL_ID\` with your Facebook Pixel ID.
